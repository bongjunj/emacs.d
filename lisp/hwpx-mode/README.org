#+title: hwpx-mode

* 설치

Emacs 29.1 이상, Org 9.6 이상과 Python 3.9 이상이 필요하다.
Python 외부 패키지는 사용하지 않는다. 다음 설정에서 경로를 설치 위치로 바꾼다.

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/hwpx-mode")
(require 'hwpx-mode)
#+end_src

=hwpx-mode.el= 과 =hwpx_bridge.py= 는 같은 디렉터리에 둔다.
Python 실행 경로는 =hwpx-python-command= 로 지정할 수 있다.

* 사용

=C-x C-f= 로 =.hwpx= 파일을 열거나 =M-x hwpx-open= 을 실행한다.
Python 3 표준 라이브러리와 Emacs 기본 Org만 사용한다.
이미 실행 중인 Emacs에서는 =M-x load-library RET hwpx-mode RET= 로 다시 불러온 뒤
문서를 새로 연다. 이전 버퍼에 저장하지 않은 편집이 있으면 먼저 사본으로 저장한다.

짧은 항목과 참석자 목록은 실제 Org 표로, 긴 셀은 Org 제목과 본문으로 표시한다.
세로 병합 셀의 제목·내용은 해당 표 앞에서 편집한다. 이 화면 배치는 원본 HWPX의
셀·문단에 연결되는 편집용 표현이며, Org에서 문서를 새로 내보내는 방식이 아니다.

- 표 안에서 직접 입력하고 =TAB= / =S-TAB= 으로 셀 사이를 이동한다.
- =C-c C-c= 로 표를 정렬한다.
- 셀 안의 기존 자동 글머리표는 Org의 =- 항목= 으로 표시하며, 하위 단계는
  들여쓰기로 표현한다. 목록은 표 아래의 본문 영역에서 수정한다. 저장할 때
  Org의 표시용 글머리표를 본문에 중복 삽입하지 않고 원래 목록 서식을 유지한다.
  =M-RET= 로 항목을 추가하고 =M-<left>= / =M-<right>= 로 단계를 바꿀 수 있다.
  항목의 줄을 지워 삭제할 수 있다.
  기존 목록의 항목에는 해당 문단의 서식을 유지하고, 새 항목과 단계에는 기존
  글머리표 서식을 바탕으로 문단 서식을 만든다. 마지막 항목을 삭제해 저장하면
  셀은 빈 문단으로 남는다. 빈 셀에 새 목록을 만드는 기능은 아직 없다.
- 긴 본문은 해당 Org 제목 아래에서 바로 수정한다. 화면에서 자동 줄바꿈한다.
  일반 개행은 Org의 문단 관례대로 공백으로 저장하며,
  명시적인 줄 나눔은 줄 끝에 역슬래시 두 개를 입력한다.
- =C-x C-s= 로 HWPX 사본을 저장한다. 첫 저장 시 이름을 선택하고,
  이후에는 선택한 파일을 갱신한다. =C-x C-w= 로 저장 경로를 다시 선택한다.
  원본 이름을 선택하면 덮어쓰기 여부를 확인한다. 원본은 저장할 때마다 확인하고,
  다른 기존 파일은 처음 저장 대상으로 선택할 때 확인한다. 거절하면 저장하지 않는다.

새 사본을 기본 저장 이름으로 제안하며, 확인 후 원본에도 덮어쓸 수 있다.
원본의 표 병합·행열·크기·테두리·
문단 및 글자 서식 속성을 보존한다. 목록 편집에서는 셀 안의 문단을 추가·삭제하거나
목록 단계에 맞는 문단 서식을 생성한다. 저장 시 변경한 목록 문단, 텍스트 요소와
재계산이 필요한 줄 배치 캐시를 제외한 XML 요소·속성이 같은지 검사한다.
변경하지 않은 저장은 원본 파일과 바이트 단위로 동일하다.
Org 표의 행·열 추가/삭제 및 편집 영역 밖의 변경은 저장 전에 거부한다.
행 이동이나 정렬은 기존 위치의 셀 내용을 서로 바꾸며, 원본 셀 서식은 그 위치에 남는다.
필드·그림 등 제어 요소가 포함된 문단은 읽기 전용이다. Org 강조·링크 등으로
HWPX 글자 서식을 새로 지정하는 기능은 제공하지 않는다.

텍스트 길이가 바뀌면 한글에서 줄과 페이지 배치를 다시 계산한다. 최종 인쇄 배치는
한글에서 확인해야 한다. 텍스트 미리보기는 갱신하며 썸네일 이미지는 갱신하지 않는다.
원본이나 저장한 사본이 다른 프로그램에서 바뀌면 저장을 중단하므로 문서를 다시 연다.
HWP 자동 변환은 사용하지 않는다.
